Aplicativo de organização pessoal com Web e Android, temas lilás claro e escuro e o fluxo **Backlog → Hold → In Progress (Do Today) → Done Today → Done**. A Web existente continua funcionando localmente até a ativação da nuvem. Não depende de uma conta Asana.

Para conectar os dois dispositivos, siga [a configuração do Supabase](SUPABASE.md) e [as instruções do Android, Expo Go e APK](mobile/README.md). As decisões de arquitetura e migração estão em [MULTIPLATAFORMA.md](MULTIPLATAFORMA.md). Nesta instalação, a migração para o projeto Supabase **Avana** foi concluída e verificada em 16/10/2026: um projeto, uma tarefa e quatro eventos foram preservados, com os mesmos IDs e vínculos. A Web usa a nuvem; o SQLite original permanece congelado como arquivo de segurança. O usuário confirmou no Expo Go o login, a mesma tarefa e a sincronização de criação e prioridade nos dois sentidos. A instalação do APK é uma validação separada.
